## 不依賴求解器的手算標準值

人工合成材料：`E_i=E_o=100 GPa`、`ᾱ=10⁻⁵/K`，來源與無應力參考皆為 300 K。`R=0.1 m`、`t_i=0.001 m`、`t_o=0.002 m`；故環向剛度和為 `300×10⁶ N/m`。壓力 1 MPa 對應環向膜力 `pR=100,000 N/m`；內殼 400 K 時自由熱應變 `0.001`。

| 工況 | 手算總應變 | ΔR (mm) | 內殼應力 (MPa) | 外殼應力 (MPa) |
| --- | ---: | ---: | ---: | ---: |
| 300/300 K、0 MPa | 0 | 0 | 0 | 0 |
| 300/300 K、1 MPa | 1/3000 | 0.0333333 | +33.3333 | +33.3333 |
| 400/300 K、0 MPa | 1/3000 | 0.0333333 | −66.6667 | +33.3333 |
| 400/300 K、1 MPa | 2/3000 | 0.0666667 | −33.3333 | +66.6667 |

由此另查 `t_iσ_i+t_oσ_o=pR`、兩殼總應變相同、熱與機械應變之和等於總應變、增厚使壓力位移減少，以及 `t_o→0` 時回到 `ΔR=pR²/(E_i t_i)`。使用有效材料溫度以外的值會報錯，不做外插。

## 測試與圖表

`tests/test_linear_shell.py` 對照上述手算值、溫度界線與彈性適用旗標。整套程式共 **22 項測試通過**，`ruff check .` 通過；這些測試不能證明真實材料或火箭結構正確。`examples/phase3a_demo.py` 產生壓力–位移、應力與熱應變圖；已實際檢視合成及 SS316 本機輸出，軸標、符號與警示文字可讀。圖上灰色虛線代表雖可代入線彈性式、但已超出所選彈性界限或界限未知的點。CSV 和 manifest 留在 Git 忽略的 `outputs/`。

本機 SS316 試算使用 `R=0.1 m`、`t_i=1 mm`、`t_o=2 mm`、`T_i=315°C`、`T_o=200°C`、`T_ref=100°C`、`p_g=1 MPa`，以上幾何與工況只是示範選值。得 `ΔR≈0.242326 mm`，但所選屈服強度表使 `elastic_prediction_credible=False`；**該位移及應力不能當作可信的線彈性實物預測**。資料來源、材料狀態與無應力參考溫度均未完成實驗確認。Phase 3B 才能在取得經驗證本構後處理塑性、軸向與載入歷史；目前不判定失效或壽命。

## Phase 3B 擴充關卡

1. 先確認材料狀態、各溫度的均勻變形區間、真塑性曲線起點與降伏／0.2% proof stress 的定義；資料缺口不得用軟體自動補出。
2. 建立能追蹤每一步應力、塑性應變與切線剛度的歷史本構，分開驗證載入、卸載及升溫順序。
3. 重新加入原文軸向平衡及軸向相容，核對泊松效應、雙軸屈服條件與邊界條件。不能把 Phase 3A 的 `σ=Eε_mech` 直接套用至此。
4. 再以文獻算例、解析極限及獨立數值模型檢查收斂與誤差，才討論塑性承載與後續通道結構。壽命預測屬更後面的階段。
