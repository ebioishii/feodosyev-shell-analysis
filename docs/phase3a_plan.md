# Phase 3A：線彈性雙層薄殼實作與驗收計畫

## 文獻核對與模型邊界

本機參考檔 `references/俄文那本/CH9_10A_en.pdf` 的 Chapter 9 §9.3，PDF 第 5–7 頁，給出薄圓筒、徑向剛性連結、忽略邊緣效應、均勻氣體壓力與殼厚平均溫度等假設。式 (9.1) 為雙殼環向平衡：`t_i σ_i + t_o σ_o = p_g R`。原文也有軸向平衡與彈塑性方程；Phase 3A 不使用它們。

`references/比較新的俄文那本/chapter_2_EN.pdf` 的 Korotkaya (2017) §2.1.1，印刷第 46–49 頁／PDF 第 3–6 頁，改用**三層**模型。式 (2.2) 是三層環向平衡，式 (2.3)–(2.5) 分別給出總應變＝機械＋熱應變、相同環向總應變及扣除熱應變。Phase 3A 取其相容關係，但只保留原 Feodosyev 雙層。文獻中的 `αT` 使用該文脈絡的溫度基準；程式採資料來源之平均熱膨脹係數先算累積應變 `β(T)`，再以案例指定的無應力溫度算 `ε_th = β(T)−β(T_ref)`。這是小應變近似；`T_ref` 與材料表的係數參考溫度須分開記錄。

Phase 3A **另外引入**單軸、零軸向應力的線彈性式 `σ_j=E_j(T_j)(ε−ε_th,j)`，並非文獻完整本構。共同半徑 `R` 指無應力參考狀態的共同名義半徑；`ε=ΔR/R`。`p_g` 是對外側零表壓的淨內壓。壓力與拉應力、向外位移為正。溫度 `T_i,T_o` 是各殼厚度平均且穩定的溫度。

## 解析式與工作順序

令 `K_i=E_i t_i`、`K_o=E_o t_o`（單位 N/m），則

`ε = [p_g R + K_i ε_th,i + K_o ε_th,o] / (K_i+K_o)`；
`ΔR=R ε`；`ε_mech,j=ε−ε_th,j`；`σ_j=E_j ε_mech,j`。

1. 實作單工況求解器與清楚的輸入／輸出資料類別。兩殼均須有正厚度，厚度必須遠小於半徑；由例外拒絕非物理數值與溫度外插。
2. 使用材料模組的 `E(T)` 與平均熱膨脹資料；降伏強度若存在，只當作**所選的暫用彈性界限**。超過時標記線彈性預測不可信，不判定失效；若界限不存在，標記未知。
3. 壓力掃描與圖表由同一求解器產生；輸出 CSV、PNG 與重現紀錄至 Git 忽略的 `outputs/`。公開範例只用人工合成材料。
4. 測試用事先手算的有理數案例核對解析式：零載荷、等溫壓力、純溫差、聯合作用；另檢查力平衡、相容、正負號、單位、厚度趨勢、單層極限、資料越界與彈性界限警示。
5. 更新 README 與 Phase 3B 路線；在獨立分支開 Draft PR，保持 Phase 2 PR 和 main 不變。

## 驗收與限制

程式驗收：獨立手算值相符，全部自動測試與 Ruff 通過；圖表軸有單位，重現紀錄有資料雜湊、設定與 Git commit。操作驗收：實際打開圖表確認可讀。材料驗收獨立：NI／SS316 性質的來源、狀態與屈服界限仍需物理核對，數值測試通過不代表真實引擎驗證。

Phase 3B 才討論軸向力、熱／壓力載入順序、經驗證的真塑性材料本構、雙軸狀態與循環歷史；現階段沒有壽命或結構失效判定。
