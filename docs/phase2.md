# Phase 2：單調曲線與暫用資料

## 軟體能力

- `evaluate_curve`：先沿應變分段線性插值，再沿相鄰溫度線性插值。
- `curve_strain_intervals`：列出指定溫度的可用應變段。相鄰溫度取區段交集，不跨資料缺口或外插。
- `convert_curve`：工程量轉真總應變或真塑性應變；需明確確認均勻變形，塑性轉換另需相容的彈性模數。無一般反向轉換。
- 2D 比較原始保留點與插值線，3D 曲面以空白保留缺口；兩者使用相同計算函式。
- 結果記錄來源與處理檔案雜湊、Git 提交和未提交狀態、設定、單位、方法及依賴版本。
- 歷史本構只有 `history_contract.py` 的介面契約；未實作卸載、循環或熱載入歷史。

## 暫用選點規則

規則版本 `visible-unique-contiguous-v1`：只接受 `visible_curve`，同溫度下重複應變的所有點全部排除；`visible_steep_segment` 和 `bridged_occlusion` 不接受。依應變排序，遇到排除點就切段。單點段無法插值，也排除。若某個溫度沒有任何可用段，停止準備資料，避免跳過該溫度而跨溫度補線。

這是可重現的保守整理規則，**不是文獻驗證結果**。保留點仍可能含圖像誤差與頸縮後的工程量。不得用這份暫用資料自動推導材料降伏、硬化參數或結構壽命。

輸入維持原樣。輸出建立獨立資料集，所有原始列及選點原因寫入 `selection_audit.csv`。同來源雜湊及規則可重跑；不同來源需選新輸出目錄。新資料集不包含 E、降伏、泊松比、熱膨脹，以免自動混用不同來源。

## 資料格式補充

schema v1 曲線可選填 `strain_intervals: [[left, right], ...]`。範圍為閉區間，端點必須是原始節點；各段必須依序排列、不重疊，且涵蓋所有儲存節點。省略時視為整條曲線連續。

資料集使用 `partial_curves: true` 表示不完整曲線，`source_status: digitized_provisional` 表示暫用來源；查詢與繪圖必須顯式傳入 `allow_provisional=True`。`auxiliary_files` 讓選點紀錄也納入結果雜湊。

若來源是暫用數位化曲線、曲線從非零應變開始，或有效區段有缺口，載入時必須標記 `partial_curves: true`；否則會報錯。完整性報告也會依資料內容重新判斷，避免漏填標記時誤稱為完整。這只檢查資料形式，無法判定實驗曲線的物理完整性。

三維曲面目前只畫所有溫度曲線共同的首尾應變範圍，因此各溫度獨有的邊緣區段不會出現在曲面上；可用區間仍以 `curve_strain_intervals` 為準。真塑性轉換若要進入 SS316 處理流程，需先記錄各溫度的均勻變形截止點、來源依據與相容的 E(T)，並據此截取曲線。使用者直接呼叫 `convert_curve(..., uniform_deformation=True)` 仍只是自行宣告前提。
