# 模型界線與資料狀態

- 目前只有材料資料與**單調、單軸拉伸**曲線。曲線查詢不追蹤載入歷史，不能用來預測卸載、殘留應變、循環壽命或雙層薄殼變形。
- `constitutive/history_contract.py` 僅規定未來歷史本構的輸入與輸出形式；目前沒有可實例化的歷史模型。
- 所有 `examples/synthetic` 數值均為人工定義，用於測試程式，**不是 SS316 的實測資料**。
- `D:\LAB\regen\references\SS316_data` 中的彈性模數、降伏強度、泊松比及平均熱膨脹 CSV 可透過明確欄位對應匯入；來源、試驗條件及轉載權限仍待查證。轉換輸出存放在 Git 忽略的 `data/processed/`。
- `SS316_mean_thermal_expansion.csv` 是以 0 °C 為參考的**平均**熱膨脹係數，不是瞬時係數。程式只在表格溫度範圍內插值，沒有由平均值推造瞬時值。
- 熱應變流程先在來源溫度點算 `β(T)=ᾱ(T0→T)(T−T0)`，然後對 `β(T)` 分段線性插值，最後用案例的無應力參考溫度算 `ε_th=β(T)−β(T_ref)`。來源的 `T0` 與案例的 `T_ref` 是兩個不同設定。只把 `β(T0)=0` 當作精確錨點，不在資料點與 `T0` 之間填補未知曲線；超出量測溫度拒絕計算。瞬時係數資料不適用這個函式。
- `mechanical_hoop_strain` 只依薄圓殼小變形關係計算 `ΔR/R−ε_th`，要求位移與半徑共用參考狀態；它不計算壓力平衡、殼間相容或彈塑性歷史，不能視為 Feodosyev 求解器。
- `SS316_plastic_StressStrain.csv` 的 2,089 筆資料均標為 `digitized_provisional`，含重複應變座標與局部遮蔽的補點，且各溫度曲線均未涵蓋初始零應變。因此匯入程式只記錄品質摘要與來源檔雜湊，**不**把它當作正式曲線供 `evaluate_curve` 使用。選點、去重、頸縮界線與來源試驗條件需另行核對。
- 內部單位為 K、Pa、m 及無因次應變。熱膨脹係數必須標示平均或瞬時種類與參考溫度。
- 插值採應變方向分段線性，再在相鄰溫度間線性插值；只在共同有效應變範圍內求值，不外插。
- 工程量轉換要求資料位於均勻變形區間；一般轉換公式不能直接延伸到頸縮之後。
- Phase 3 之前，須核對 Feodosyev Chapter 9 §9.3 與 Korotkaya (2017) §2.1.1 的方程、符號、邊界條件與適用性。本文尚未驗證這些文獻方程。
