# 階段 2：Feodosyev 壓力－環向總應變曲線

## 範圍

`feodosyev_curve.py` 只在研究者指定的環向總應變範圍內，逐點呼叫已驗證的 `feodosyev_single_point.py`。它輸出實際算得的 `p_g-epsilon_theta,total` 曲線與每點資料。

本模組刻意不做以下事情：

- 不判定 Fig. 9.7 的 A、B、C、D。
- 不強迫曲線出現四個階段。
- 不做平滑曲線或多項式擬合來改變實際形狀。
- 不把指定的最後一個應變點稱為承載極限或失效點。
- 不修改既有一維模型或 HTML。

## 軸向應變分支連續性

每個單點仍完整搜尋共同材料有效範圍內的式 (9.5) 根：

1. 第一點若只有一個根，就直接採用。
2. 第一點若有多根，必須由 `initial_axial_strain_guess` 指定要靠近哪一支；程式不自行猜測。
3. 第二點以第一點的軸向總應變作為猜測。
4. 第三點起，以前兩個已接受點做線性外推，再由單點求解器選擇最靠近預測值的根。

CSV 會保存每點的猜測值、實際軸向增量、預測誤差、找到的根數和選根方式。這能檢查程式是否突然跳到另一支，而不是只看最後的曲線圖。

## 每點硬性檢查

任何一點不通過，整次掃描立即停止，錯誤訊息會包含點號和環向總應變：

- 式 (9.1)、(9.2)、(9.5) 殘差必須低於單點求解器的容許值。
- Inner／Outer 的應變強度都必須在各自 Granta 曲線範圍內。
- 單軸總機械應變必須等於彈性應變加塑性應變。
- 氣體壓力不得顯著小於零。
- 所有輸入應變必須有限且嚴格遞增。

壓力下降的區段只會被計數並忠實保留，不會被刪除或改判為錯誤，因為曲線實際形狀正是此階段要觀察的對象。

## 輸出

CSV 每列包含：

- 共同環向與軸向總應變、`p_g`。
- Inner／Outer 的軸向應力、環向應力與應力強度。
- Inner／Outer 的機械應變、應變強度，以及單軸彈性／塑性應變分解。
- 三個平衡殘差、殘差容許值及相對殘差。
- 軸向分支預測資訊、根數和材料分支。

PNG 只以線段連接實際計算點。標題明確註明沒有 A–D 判定，終點也不是自動識別的承載極限。

為保護研究輸出，若同名 CSV 或 PNG 已存在，程式會拒絕覆寫。

## 執行範例

```powershell
python feodosyev_curve.py `
  --radius-mm 100 `
  --inner-thickness-mm 1 `
  --outer-thickness-mm 2 `
  --inner-temperature-c 538 `
  --outer-temperature-c 20 `
  --start-hoop-strain 0.00025 `
  --end-hoop-strain 0.03 `
  --points 121 `
  --k 0.5 `
  --output-directory outputs `
  --prefix feodosyev_stage2_curve
```

`start-hoop-strain` 與 `end-hoop-strain` 都會包含在輸出中。上述 `0.00025` 只是目前本機 SS316 範例中能得到非負壓力的示範起點，不是通用材料常數，也不是自動判定的零壓點。
