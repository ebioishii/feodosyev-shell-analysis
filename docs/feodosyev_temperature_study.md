## 溫度與材料有效範圍

先分別檢查彈性模數、熱膨脹係數及硬化曲線的溫度範圍，再建立材料模型。任何一項超出範圍，該案例都記為 incomplete，禁止外插。

目前本機資料的溫度範圍為：

| 性質 | 有效溫度範圍 (C) |
| --- | --- |
| 彈性模數 | -198.3 至 815.6 |
| 熱膨脹係數 | -260.2 至 999.9 |
| 硬化曲線 | -269.2 至 816.0 |

七個指定 Inner 溫度與固定的 Outer 20 C 都在共同有效範圍內。應變範圍仍須逐點另外檢查，溫度有效不代表任意應變都有效。

## 各案例的零壓力起點

不同溫度不共用 0.025% 起點。程式先以兩殼各自的自由熱應變為搜尋區間端點：

1. 在兩端之間取 17 點，呼叫既有單點求解器。只有此步與零壓力求根會明確允許負壓力數學解。
2. 所有點仍須通過平衡、材料有效範圍及唯一軸向根檢查；失敗點不跳過。若沒有唯一負到正壓力交點，案例標記為未完成。
3. 在找到的括區內以 Brent 方法解 `p_g=0`，應變絕對容許值為 `1e-14`。
4. 保留夾住交點的負壓力下界及非負壓力上界，必要時再縮小括區。選取上界作為曲線起點，要求括區寬度不大於 `1e-12`，且原始壓力介於 0 與單點平衡容許值除以半徑之間（本例為 0.01 Pa）。若找到恰為零的點，使用該點。
5. 起點壓力以實際計算值保存，不把它改寫成零。這是零壓力根的數值包絡，不是任意向右截掉不利數據。

`evaluations.csv` 保存正、負試算點、求根目的、是否使用快取、四個應力與平衡殘差。`result.json` 記錄初始搜尋區間、最終括區、寬度、起點實際壓力及容許值。這些紀錄能檢查曲線從何處開始，以及零壓力交點是如何得到的。

## 曲線、事件與最低強度

每個案例從自己的零壓力起點均勻取樣至共同總環向應變 0.03（3%），預設 481 點。每條曲線使用原曲線模組的軸向分支延續方式，不刪除下降區段、不平滑，也不把終點當成極限應變。

原診斷模組輸出壓力、四個應力、兩殼應力強度/初始降伏參考、材料圖分支與局部切線。切線維持 Pa / 單位應變；換成 MPa / 百分點應變時除以 `1e8`。

以下物理條件均以額外單點求解縮小，而不是僅在兩個取樣點間畫線猜位置：

- Outer 初次達到初始降伏參考：解 `epsilon_i,outer / (sigma_y0,outer/E_outer) - 1 = 0`。使用應變強度可避免硬化段應力變化小造成過大的線性插值偏差。
- Inner 環向壓縮轉拉伸：解 `sigma_theta,inner = 0`。
- Inner 進入與離開低於初始降伏參考的區間：以同樣的應變強度門檻求根，並檢查區間內的點。

若條件在零壓力起點就已達到，結果明確標記 already_at_or_above_at_start；不把起點誤稱為首次降伏位置。範圍內未出現則標記 not_reached，保持空值。

Inner 最低強度比先在網格上搜尋，再對所有已解析出的局部低點括區，以及端點附近可能藏有低點的區間，做有界最小化。摘要分別保留取樣最小值與加密最小值。若加密低點低於門檻，它也會加入門檻交點搜尋，避免只因原網格漏掉狹窄區間就漏報。

這是有限網格加局部加密的最小值搜尋，不是任意材料曲線的全域最小值數學證明；使用不同網格密度驗證解析度仍有必要。

## 成功與失敗條件

成功案例要求：

- 所有前向曲線點通過式 (9.1)、(9.2)、(9.5) 平衡、材料範圍與嚴格非負的原始壓力檢查。
- 所有取樣點、零壓力搜尋點及加密點只有一個偵測到的軸向根。若出現多根，本參數研究保守標記未完成，沒有替使用者挑選不明分支。
- 原診斷模組能計算有限、非奇異的局部切線。
- 在含端點的 17 個位置從大應變往小應變反向求解，與前向軸向根差異不超過 `1e-10`。
- 加密最小值與解析出的低於降伏區間判斷一致。

這些是取樣與額外檢查點的連續分支證據，不能排除所有有限取樣都未看見的根或極窄特徵。

某案例失敗時，其他案例仍能完成，但摘要保留該溫度、incomplete 狀態與具體原因。低層計算函式拋出帶有搜尋紀錄的例外；批次層將它保存成失敗結果。CLI 若有任一未完成案例，結束碼為 1。比較圖也會列出未完成溫度，而不補造曲線。

## 物理解讀邊界

Inner 溫度改變會同時改變自由熱應變、彈性模數、初始降伏參考與硬化圖。本研究只能量化它們的綜合影響，不能把兩條曲線的差異全歸因於熱膨脹或材料軟化。資料的溫度相依性也不必然單調，不能先假設升溫一定降低所有承載指標。

低於初始降伏參考表示目前固定溫度、變形理論材料圖的當前狀態；不表示真實材料的累積塑性應變恢復或歷史被消除。本研究不推論彈性卸載、反向降伏、循環壽命，不作 A–D 分類、失效壓力或操作極限判定。

在這七種溫度及已解析範圍內，Inner 最低強度比都高於 1，且所有曲線樣本均在 plastic 材料圖分支。300 C 最接近門檻，但加密最低值仍高約 1.63%。這不支持把中段斜率回升解釋為 Inner 回到低於初始降伏的狀態；也不能延伸宣稱所有未測試溫度都不可能低於門檻。

Outer 初始降伏位置集中在約 0.095% 應變附近；Inner 環向應力過零位置則由 300 C 的約 0.587% 延後至 650 C 的約 1.489%。因此改變 Inner 溫度主要可見的現象之一，是 Inner 從抵消環向承載轉為分擔拉伸合力的位置移動。環向應力仍為負時，內殼環向應力的增量已可能對壓力切線有正貢獻；必須區分「總承載合力的符號」與「增量剛性貢獻」。

為比較增量承載，取各曲線最靠近其 Inner 環向過零位置的實際樣本，得到：

| Inner 溫度 (C) | 該樣本壓力切線 (MPa / 1% 應變) | Inner 對總切線的貢獻比例 |
| --- | --- | --- |
| 300 | 13.6232 | 92.06% |
| 400 | 8.7294 | 88.31% |
| 450 | 7.2595 | 86.12% |
| 500 | 6.1682 | 84.02% |
| 538 | 5.5113 | 82.41% |
| 600 | 3.6372 | 74.77% |
| 650 | 4.5437 | 79.01% |

這些比例是壓力曲線的切線分擔，不是該點總壓力的分擔比例。在環向過零附近，大小項因環向正規化分量接近零而自然變小，方向項通常佔優勢；不能僅憑該位置的方向項比例，就把整條曲線的溫度差異歸因於單一機制。詳細的 magnitude/direction 分解及各位置斜率都留在 `points.csv`。

曲線會交叉，而且溫度效應並非全面單調：3% 端點壓力從 600 C 的約 9.4766 MPa 回升至 650 C 的約 9.7461 MPa，最低強度比反而由約 1.12926 降至 1.09019。既有 Granta 模型的初始降伏參考在 600–650 C 也不是單調下降。本次保留該溫度相依關係，沒有為了曲線順序改動資料或形狀，也沒有把綜合溫度影響拆成熱膨脹與材料軟化的獨立因果。

## 驗證結果

- 既有 19 個測試與新增 6 個測試全部通過。新增項目包括：解析零壓力位置與最低強度位置、保留負壓力紀錄、七個指定溫度、538 C 基準、無解的具體錯誤與追蹤紀錄、禁止外插、失敗案例 CSV 空值及 CLI 非零結束碼。
- 538 C 加密最低強度比為 `1.0625307870542`，重現階段 3 約 `1.06253`；Outer 初始降伏與 Inner 環向過零位置分別約 `0.0009564477652`、`0.0119010767821`。3% 壓力維持 `9.870053090485204 MPa`。
- 所有 3,367 個主曲線點均通過平衡、材料範圍、唯一偵測軸向根與非負壓力檢查。最大平衡殘差約 `6.03e-7 N/m`，低於原求解器 `1e-3 N/m` 的絕對門檻；兩殼材料有效範圍的最大使用率約 9.01%。
