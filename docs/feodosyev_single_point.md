# Feodosyev §9.3 單點求解器

## 來源與實作範圍

`feodosyev_single_point.py` 依本機研究文獻 Chapter 9 §9.3 的式 (9.1)–(9.6) 實作。公式已同時用 PDF 文字抽取與頁面渲染核對；原始文獻及翻譯 PDF 不納入 Git。

本階段只做一件事：給定共同環向總應變 `epsilon_y_total`，求共同軸向總應變 `epsilon_x_total`、兩殼的軸向／環向應力，以及氣體壓力。沒有掃描整條曲線，也沒有判定 Fig. 9.7 的 A–D 階段。

## 方程對應

採用 `x = axial`、`y = hoop/circumferential`：

1. 式 (9.1)：`sigma_y_inner*h_inner + sigma_y_outer*h_outer = p_g*R`
2. 式 (9.2)：`sigma_x_inner*h_inner + sigma_x_outer*h_outer = k*p_g*R`
3. 式 (9.3)：每一殼、每一方向均使用「總應變 = 機械應變 + 熱應變」，兩殼共用同一軸向總應變及同一環向總應變。
4. 式 (9.4)：先算應變強度，再由單軸拉伸圖取得應力強度，最後用原文的割線形式算 `sigma_x`、`sigma_y`。
5. 式 (9.5)：求根殘差為兩殼軸向合力減去 `k` 倍環向合力。
6. 式 (9.6)：求根後，以環向合力除以半徑得到 `p_g`。

所有內部單位均為 SI：長度 m、應力／壓力 Pa、應變無因次。CLI 的幾何輸入則使用 mm，進入求解器前才換算。

## Granta 應變欄位的正確用法

`Isotropic Hardening.csv` 的橫軸是塑性應變 `epsilon_p`，不能直接當成式 (9.4) 的應變強度。對每個溫度，程式使用：

```text
uniaxial total mechanical strain
    = plastic strain + stress / E(T)
```

因此材料回應會明確保留三個量：

- `total_mechanical_strain`
- `elastic_strain = stress/E(T)`
- `plastic_strain`

塑性段使用上述關係的精確分段線性反函數：先把既有溫度插值曲線的所有轉折點
轉到總機械應變軸，再直接查值。溫度位於兩張表之間時，使用兩張表節點的聯集，
並呼叫既有 `flow_stress` 計算節點應力，不額外取樣、平滑或更換插值公式。
同溫度曲線最多快取 64 組，僅留在記憶體。彈性段仍使用 `stress = E(T)*strain`。
超出 Granta 曲線範圍時停止，不外插。

## 數值與物理解保護

- 應變強度接近零時，`sigma_i/epsilon_i` 使用彈性極限 `E(T)`，避免 `0/0`。
- 先由兩殼材料曲線上限求出共同軸向應變的有效交集，只在此範圍找根。
- 對內建材料，先計算式 (9.5) 在整個有效範圍的導數下界。只有下界嚴格大於零，
  才使用兩端括住的唯一根，省去全範圍掃描。證明不成立、零切線或自訂材料，
  仍使用原有全範圍掃描；多根仍必須提供 `axial_strain_guess`。
- 預設拒絕需要顯著負氣體壓力的數學解；研究者可明確開啟 `allow_negative_pressure` 查看。
- 回傳式 (9.1)、(9.2)、(9.5) 的 N/m 殘差、容許值與相對殘差。
- 另外從 `sigma_x`、`sigma_y` 反算應力強度，確認它與式 (9.4) 使用的 `sigma_i` 一致。

式 (9.6) 本來就是由式 (9.1) 改寫，所以程式用式 (9.6) 算出壓力後，式 (9.1) 殘差理應只剩浮點四捨五入誤差；同理，代入式 (9.6) 後，式 (9.2) 與式 (9.5) 是同一個獨立平衡條件。三個值仍全部輸出，讓單位、代入與程式欄位錯置都能被看見，但不把它們誤稱為三項彼此獨立的證據。

## 可獨立手算的簡化案例

若兩殼材料、溫度都相同且保持線彈性，厚度加權會從式 (9.5) 約去。把共同機械環向應變記為 `ey`，可直接解得：

```text
ex = ((k - 0.5) / (1 - 0.5*k)) * ey
```

測試採用 `E=200 GPa`、`k=0.35`、熱應變 `0.0002`、總環向應變 `0.0012`、兩殼厚度 `1 mm` 與 `2 mm`、半徑 `100 mm`。因此：

```text
mechanical ey = 0.001
mechanical ex = -0.0001818181818...
total axial strain = 0.00001818181818...
hoop stress = 242.424242... MPa
p_g = 7.272727... MPa
```

這個案例不依賴 Granta 資料或數值答案，可直接代回式 (9.2)/(9.5) 檢查 `sigma_x = k*sigma_y`，並用式 (9.6) 檢查壓力。

## 使用方式

本機要先備妥 README 所列的 Granta CSV：

```powershell
python feodosyev_single_point.py `
  --radius-mm 100 `
  --inner-thickness-mm 1 `
  --outer-thickness-mm 2 `
  --inner-temperature-c 538 `
  --outer-temperature-c 20 `
  --hoop-strain 0.002 `
  --k 0.5
```

輸出是單一 JSON 物件，包含共同軸向應變、四個應力、`p_g`、兩殼的彈性／塑性／總機械應變分解，以及三個平衡殘差。

## 適用限制

這是原文的薄壁、共同半徑、軸對稱溫度、雙軸主應力與變形理論模型。式 (9.4) 把當前應變強度映射到單軸拉伸圖，是割線式、路徑無關的表示；它不是一般三維增量 J2 彈塑性更新，不能用來描述卸載、反向載入、循環塑性或任意三維應力路徑。

Granta 硬化資料只在其原始溫度與塑性應變範圍內使用。單點解也沒有上一點可提供的分支連續性；若出現多根，仍需後續曲線階段的載入歷史才能判定物理分支。
