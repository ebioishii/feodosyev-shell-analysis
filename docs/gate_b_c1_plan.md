# Gate B 與 C1：驗證計畫及目前狀態

本計畫以 [Lv et al. (2022)](https://doi.org/10.3390/met12091421) 的出版社 PDF 與本機數位化 Fig. 2(a) CSV 為依據。出版社 PDF、數位化 CSV、疊合圖與逐點誤差表只保存在 `outputs/phase2_validation/` 或 `D:/LAB/regen/references/`，不提交 GitHub。驗證程式 `scripts/validate_phase2.py` 和合成資料測試可公開重跑。

## Gate B：原圖及插值

1. 已將 Fig. 2(a) 的六條保留曲線疊上出版社 PDF，按圖面座標校準，量化保留點至對應彩色印刷線的像素距離。這是印刷圖重建檢查，不能表示實驗儀器誤差。
2. 已對照 Fig. 2(b) 的 UTS 趨勢及文字所列數值，並將 Fig. 2(c) 的「均勻」與「總」延伸率分開。20、750°C 為平滑曲線，350–650°C 有鋸齒；450°C 遮蔽區保持缺口。論文方法節未列 650°C，但 Fig. 2 有 650°C；待作者釐清。
3. 已以留一溫度法比較線性與 PCHIP。兩方法採相同的目標保留節點，且只在所需曲線共同有效、各曲線峰值 proxy 之前比較。不跨缺口、不外插。線性仍是正式查詢介面的預設；PCHIP 目前只用於驗證研究。
4. 後續需要作者原始曲線與數值表，才能核對印刷圖的數位化誤差、重複試片散布，以及在獨立試驗上的插值泛化能力。

## Gate C1：均勻變形證據

1. 已逐溫度整理數位化最大工程應力及峰值應變。Fig. 2(c) 有 uniform elongation，但圖上估值與工程應力峰值應變並不相同；六組正式 `uniform_strain_limit` 均為 `unverified`。
2. 各溫度初始彈性段都缺失；350、450°C 有內部缺口。350–550°C 的剪切帶及 350–650°C 的鋸齒行為，使單一平滑硬化曲線的適用性更窄。750°C 的總延伸率大幅高於均勻延伸率，後頸縮部分不能用一般工程→真量公式直接轉換。
3. 等待作者確認 uniform elongation 的逐點值與量測定義、necking onset、650°C 試驗條件、原始載荷／伸長資料，以及 450°C 被遮蔽曲線。核准 cutoff 前，不產生正式真塑性資料集。

## Gate C2：僅規劃

建立每溫度的 `cutoff`、證據來源、信心及核准狀態欄位；核准後先裁切，再以同試片條件相容的 E(T) 計算真塑性應變。將缺少的初始段與資料缺口留為不可用；檢查 0.2% proof stress 與初始降伏定義；對 DSA 區保留鋸齒及應變率限制，並量化擬合不確定性。正式 `σ_flow=f(ε_p,T)` 候選需另立測試基準。Phase 3 暫不開始。
