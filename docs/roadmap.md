# 開發路線與驗收

| 階段 | 交付與依賴 | 驗收狀態 |
| --- | --- | --- |
| 0 | 環境、Git、Private GitHub、README、CI | 待檢查 |
| 1 | 資料格式、品質檢查、SS316 既有 CSV 明確匯入 | 程式可測；來源待核對 |
| 2 | 單調曲線、轉換、插值、Notebook、互動圖 | 軟體與暫用資料流程完成；27 項測試、兩份 Notebook 通過；VS Code 人工操作與正式材料證據待補，見 [驗收明細](phase2.md) |

每階段分開記錄：程式進度、自動測試、人工操作驗收及缺少的研究證據。正式版本標籤規劃為 `v0.1.0`、`v0.2.0`、`v0.3.0`；實際建立標籤應在相應階段驗收後。

Phase 3 的主要輸入預期為 `R, t_i, t_o, T_i, T_o, p_g`，另須記錄材料、無應力參考溫度與載入順序。先驗證零載荷、單層極限、等溫彈性及溫差自平衡，再研究降伏和塑性發展。
