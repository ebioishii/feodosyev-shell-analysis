# 四階段物理條件的診斷與驗證

## 本次結論

以階段 2 Commit `83bd9a337eb537288355f92085dc8aecdd937ef8` 為基準，保留相同材料、幾何、溫度與 `k`。本例支持「外殼先降伏，內殼環向應力由壓縮轉為拉伸，逐漸分擔環向壓力合力」的部分機制。但內殼在整段掃描都位於目前材料圖的塑性分支，不能把中段斜率回升稱為內殼回到未降伏、高彈性剛性的證據。

本次只做物理診斷，不自動分配 A–D，也不辨識承載極限。單點求解器、階段 2 曲線模組、一維模型和 HTML 的原始碼均保持不變。

## 來源與要核對的條件

來源為 Gakhun 等人 (1989)《Конструкция и проектирование жидкостных ракетных двигателей》§9.3，印刷頁 175–177；四段敘述主要在頁 176–177。[原書掃描與 OCR](https://djvu.online/file/HVHuXXppma9Ey)。另與本機 `CH9_10A_en.pdf` 第 8–9 頁對照；該翻譯的圖像連結有缺失，因此沒有從翻譯圖讀取數字。

以下是原文定性條件與本例的對照，不是對計算點自動分段：

| 原文敘述 | 本例檢查結果 |
| --- | --- |
| 初段：內殼受壓、外殼受拉，外殼未超過降伏，斜率高 | 符合這組條件；早期斜率主要由外殼提供 |
| 隨後：外殼降伏，內殼仍受環向壓縮，斜率降低 | 外殼的材料圖分支由 elastic 轉為 plastic，且內殼環向應力仍為負 |
| 中段：內殼開始分擔拉伸，且原文稱其應力未超過降伏，斜率回升 | 環向拉伸與承載貢獻增加有證據；若以雙軸應力強度判斷，內殼並未回到未降伏狀態 |
| 後段：兩殼降伏、斜率降低 | 兩殼目前皆在塑性分支且斜率降低，但內殼先前已在塑性分支，沒有觀察到新的內殼初始降伏事件 |

原文這段定性敘述沒有逐句明定「應力」是環向分量或應力強度。此診斷同時輸出兩者，不能從環向分量低於單軸降伏值就推論雙軸材料尚未降伏。Fig. 9.7 是典型圖；本例兩殼都使用 SS316，不是原圖已知材料與溫度的定量重現。

## 三個量分開看

1. **環向應力符號**：`sigma_theta < 0` 是壓縮，`> 0` 是拉伸；輸出的 near_zero 容許值為 1 Pa。
2. **雙軸應力強度與初始降伏參考**：平面主應力下，`sigma_i = sqrt(sigma_x^2 + sigma_theta^2 - sigma_x*sigma_theta)`。比較 `sigma_i / sigma_y0(T)`，而不是只比較 `abs(sigma_theta)`。
3. **目前材料圖的塑性分支**：由式 (9.4) 使用的應變強度映射至單軸總機械應變圖。Granta 的初始降伏參考使用 `flow_stress(T, 0)`，其對應總機械應變為 `sigma_y0(T)/E(T)`。這是本材料模型的初始門檻，不把它默認為原書所有材料的相同 0.2% 規定塑性延伸強度定義。

`uniaxial_plastic_strain` 仍是目前單軸圖上的座標。它可能隨應變強度降低而變小，並非增量塑性模型的累積塑性歷史。本例內殼先降低再提高的塑性座標，不能解讀成真實累積塑性應變消失。

## 局部斜率及其驗證

`feodosyev_diagnostics.py` 對相同曲線計算兩種斜率：

- `pressure_slope_grid_pa_per_strain`：以相鄰點作二階有限差分，支援不等距網格；端點使用單側三點公式。
- `pressure_slope_implicit_pa_per_strain`：在固定半徑、厚度、溫度與 `k` 下，微分式 (9.4)–(9.6)。這是原文變形理論的當前曲線切線，不是增量 J2 材料切線。

以 `a` 表示共同軸向總應變，`b` 表示共同環向總應變，`J` 表示一殼的 `d(sigma_x,sigma_theta)/d(a,b)`。先令式 (9.5) 的殘差為 `F(a,b)`，則：

```text
F_a = sum[h * (J_xx - k*J_theta,x)]
F_b = sum[h * (J_x,theta - k*J_theta,theta)]
da/db = -F_b/F_a
dp/db = sum[h/R * (J_theta,x * da/db + J_theta,theta)]
```

程式拒絕近乎奇異的 `F_a`，而不輸出虛假的有限斜率。每殼的 `h/R*d(sigma_theta)/db` 就是該殼對壓力斜率的貢獻，兩殼相加必須等於總切線。

另將一殼的應力寫成 `sigma_vector = (4/3)*sigma_i*(v/epsilon_i)`，其中 `v=(e_x+0.5*e_theta, e_theta+0.5*e_x)`，即可分解成：

- magnitude：單軸圖上 `sigma_i` 的改變。
- direction：固定 `sigma_i` 時，雙軸正規化應力方向的改變。

這裡的 direction 是軸向與環向應力分量的相對變化，不是殼體幾何轉動。兩項沿同一個平衡解的 `da/db` 計算，不代表兩個可獨立載入的結構。零應變強度時方向未定義，採用原求解器的彈性極限，該點不作有意義的方向歸因。

單軸圖斜率對**總機械應變**做中心微分（預設步長 `1e-7`，邊界改用可用單側區間），並保存半步長的差異。Granta 是分段插值，在降伏或硬化曲線節點處切線可能不唯一；跨過這些位置的網格差分是區間平均，不能要求與單側局部切線相同。恰落折點時，數值材料切線可能是左右平均。

## 基準案例數值

固定條件：`R=100 mm`、`h_inner=1 mm`、`h_outer=2 mm`、`T_inner=538 C`、`T_outer=20 C`、`k=0.5`。範圍為總環向應變 `0.00025–0.03`（`0.025%–3%`）。本例溫度是階段 2 的示範輸入，不宣稱為原書 Fig. 9.7 的實際工作溫度。

## 已完成的驗證與限制

- 481 點中的負壓力與多重根點皆為 0；最大平衡殘差約 `4.46e-7 N/m`，最大相對殘差約 `1.13e-12`。
- 所有點均在材料有效範圍內；內、外殼最大材料應變範圍使用率分別約 5.22% 與 8.17%。
- 與階段 2 的 121 個共同點比較，壓力差為 0 Pa，保留原基準結果。
- 241 與 481 點比較：內點網格斜率對隱式切線的相對差中位數，由約 `6.40e-5` 降至 `1.54e-5`；95 百分位由 `5.81e-4` 降至 `1.19e-4`。跨外殼降伏折點處差異仍可能很大，不能稱為全點一致收斂。
- 排除外殼降伏附近 `0.00085–0.0011` 後，241/481 點共同點的網格斜率差相對於細網格切線，中位數約 `4.71e-5`，最大約 3.21%；最大差仍受分段材料插值折點影響。
- 線彈性壓力切線與封閉解析解相符；非線性材料 Jacobian 另以應力分量微擾確認；SS316 代表點以 `epsilon_theta +/- 1e-7` 重新解平衡，確認隱式斜率。

本次證據能區分環向承載轉換與材料圖狀態，但無法證明實際受熱後加壓歷程的彈性卸載、反向降伏或累積塑性。若要解釋原文完整四段機制，仍需釐清其定性敘述所指的應力、材料選擇及卸載假設；本次不修改式 (9.4) 來配合圖形。

```powershell
.\.venv\Scripts\python.exe -m feodosyev_diagnostics `
  --points 481 `
  --output-directory outputs/stage3-physics-20261018 `
  --prefix my_diagnostics

.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

CLI 的幾何、溫度、應變範圍、`k` 與分支初始猜測可修改。每次輸出診斷 CSV、JSON 摘要、六面板 PNG，並另輸出原始壓力曲線 CSV/PNG。同名檔案會拒絕覆寫。JSON 與圖中的最後取樣點均不代表承載極限。

CSV 保留所有階段 2 欄位，另外加入各殼工作溫度、初始降伏參考、環向/軸向應力符號、強度比、材料範圍使用率、總機械應變圖切線、半步長敏感度、兩種壓力斜率與內外殼分解。JSON 中的過零與降伏資料是取樣括區，附線性估計；它們不能代替額外求根的精確位置，也不是階段標籤。
