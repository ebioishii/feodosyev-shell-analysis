# Phase 2～3B-2.5 整合審查（2026-10-15）

審查範圍是 Draft PR #5 的 Phase 2／3A／3B-1／3B-2 整合版本，以及接在其後的 Draft PR #6。這份紀錄用於軟體合併驗收；不把合成案例通過視為 SS316 材料或實際引擎已驗證。

## 審查發現與修正

1. **壓力步長不整除上限時，載入終點不一致。** 3B-2.5 原本以 `arange(step, maximum + step/2, step)` 建立序列。例如最大壓力 6 MPa、步長 0.7 MPa 時會到 6.3 MPa；步長 4 MPa 時只到 4 MPa。這會讓步長比較混入不同最終載荷的影響。已改為先生成小於上限的步驟，再加上恰好 6 MPa 的終點，最後一步可較短。新增 0.7、4、7 MPa 步長以及零、負值、NaN、無限值的測試。
2. **塑性解析測試原以單軸為主。** 新增等雙軸拉伸的獨立手算對照：`E=100 GPa`、`ν=0.3`、初始降伏 200 MPa、降伏後切線 10 GPa，指定累積等效塑性應變 `q=0.002`。J2 流動方向為 `(1/2,1/2,−1)`，因此兩個面內塑性應變皆為 `0.001`、厚度塑性應變為 `−0.002`，兩個拉應力皆為 `222.222222 MPa`。測試核對應力、三個塑性應變分量、累積塑性量，以及卸載後零應力且保留塑性狀態。
3. **補齊 3B-2.5 重現資訊。** manifest 明列幾何、軸向力比例、單位、Python／套件版本、鎖定檔及範例程式雜湊，連同原有材料來源雜湊、參數及 Git 狀態保留於本機。

本次沒有修改求解器本構公式；審查修正集中在載入序列、獨立驗證與重現紀錄。原有的熱應變參考、雙殼共同應變、膜力平衡及合成材料限制仍保留。

## Phase 3B-3 的材料關卡

材料資料到齊後依序處理：

1. 確認試片牌號、製程／熱處理、應變量測方式、溫度與應變率，保留原始檔和來源。
2. 為各溫度建立有證據的均勻變形截止點；工程應力峰值只能作暫用近似，不能自動視為已確認頸縮點。
3. 確認各溫度的初始曲線、應變零點、0.2% proof stress 與初始降伏定義，以及 E(T) 是否適用於同一批試片。
4. 在通過的有效區間內轉換真應力／真塑性應變，檢查單位與物理合理性，不補造缺失曲線。
5. 再決定硬化模型、DSA 近似與適用條件，建立獨立驗證和不確定性範圍後，才將真實材料接入結構求解。

現有暫用工程曲線維持探索性用途；本次沒有生成正式 SS316 塑性參數，也沒有進入壽命預測。
