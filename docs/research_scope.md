# 研究範圍

## 目標

重建 Feodosyev Chapter 9 §9.3 的雙層圓筒理論，理解原文方程、求解流程及壓力–應變關係，最後嘗試重現 Fig. 9.7。重點是確認 Inner／Outer 的四個階段各自採用的假設、材料關係與轉換條件。

## 開發順序

1. 確認原始文獻的版本、頁碼、Fig. 9.7 與 §9.3 的完整上下文。
2. 逐式記錄原文的符號、幾何、載荷、邊界條件、平衡與相容關係；註明任何自行推導。
3. 釐清原文的應力–應變本構及四階段判定，不以未驗證的現代材料模型代替。
4. 先用可手算的極限案例驗證，再建立最小 Python 求解器。
5. 以明確的單位與參數重建壓力–應變曲線，記錄與 Fig. 9.7 的差異。
6. 分析內、外層在各階段的應力、應變與適用範圍。

## 現階段界線

尚未核對原文方程，故不宣稱已重現理論或圖形。此階段不建立求解器、材料模型、Notebook、疲勞、潛變、循環塑性、AM 材料或火箭引擎壽命分析。私人文獻、研究資料與輸出保留於本機封存，不納入 Git。
