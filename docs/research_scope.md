# 研究範圍

## 目標

重建 Feodosyev Chapter 9 §9.3 的雙薄殼理論，理解原文方程、求解流程及壓力–應變關係，最後嘗試重現 Fig. 9.7。重點是確認 Inner／Outer 的四個階段各自採用的假設、材料關係與轉換條件。

## 已有但必須分開看待的一維模型

專案已有一套以共同環向總應變為控制量的一維雙殼程式與本機 HTML 介面。它包含溫度相容、環向平衡、單軸增量塑性歷史及資料匯出，但沒有 Feodosyev §9.3 的軸向平衡與原文雙軸本構。因此：

- 可用來保存既有工作、檢查 UI 與一維材料資料流程。
- 不可把其結果宣稱為完整式 (9.1)–(9.6) 解。
- 新的 Feodosyev 單點求解器必須放在獨立模組，不改寫既有一維模型。

## 分階段開發

1. 保存並回歸驗證既有一維模型與 HTML 介面。
2. 依式 (9.1)–(9.6) 建立獨立單點求解器，先驗證簡化案例。
3. 後續才掃描共同環向應變，建立壓力–應變曲線。
4. 後續才分析 Fig. 9.7 的四階段降伏狀態。
5. 最後才與既有一維模型及 ANSYS 比較。

## 資料與證據界線

- Granta 原始材料檔、原始文獻與 ANSYS 專案不提交到 Git。
- 程式測試、解析簡化案例與數值殘差要分開回報。
- 通過數值求解器不等於已證明物理解；仍需檢查解的分支、材料曲線範圍與平衡殘差。
- Feodosyev 式 (9.4) 的假設不以一般三維增量 J2 彈塑性模型替換。
